# Dayline implementation plan

> Execute inline using superpowers:executing-plans. User approved implementation and public publishing. New repository provides isolation from existing projects.

**Goal:** Native GNOME 50 panel todo list with a today counter, calendar, undated notes, and polished Polish UI.

**Architecture:** Portable immutable domain model; GIO atomic persistence; St popup and widgets; GTK/libadwaita backup preferences. Lifecycle owned by the extension, including midnight/resume refresh and signal cleanup.

**Tech stack:** GJS ES modules, St, Clutter, GIO, GLib, GTK4, libadwaita, Node built-in tests, shell packaging.

Model assignments describe task complexity; execution stays with the current session model.
